# Дильназ — Қыз ұзату

Интерактивное приглашение на қыз ұзату.
**Дата:** 6 тамыз 2026, **уақыт:** сағат 17:00 (Астана), **той иелері:** Қайрат & Айгүл.

```
.
├── index.html            ← само приглашение
├── admin.html            ← локальная страничка для скачивания RSVP в .xlsx
├── apps-script.gs        ← код для Google Apps Script (RSVP → Google Sheet)
├── README.md
└── assets/
    ├── styles.css
    ├── script.js
    ├── music.mp3            ← положи сюда свою музыку
    ├── bride.jpg            ← фото невесты (4:5, ≥800px по короткой стороне)
    └── florals/
        └── branch.png       ← золотой floral PNG (используется и сверху, и снизу обложки — снизу зеркалится автоматически)
```

> Любой из файлов в `assets/` отсутствует — страница работает без него (фото и florals скрываются, кнопка музыки автоматически muted). Так что можно деплоить даже без всех ассетов и подкладывать их потом.

## 1. Локальный запуск

Открой `index.html` двойным кликом. Готово.

Для более «настоящего» окружения (с правильной работой fetch и audio):

```bash
cd "Dilnaz uzatu"
python3 -m http.server 8080
# открой http://localhost:8080
```

## 2. Музыка 🎵

1. Положи свой `.mp3` файл по пути `assets/music.mp3` (имя должно совпадать).
2. Музыка стартует, когда гость **тапает по конверту** на первом экране — это считается user gesture, поэтому браузеры разрешают автоплей.
3. Сверху справа появится кнопка mute/unmute.

> Если файла нет, страница работает как обычно — просто без звука. Кнопка автоматически переходит в muted-состояние.

Хочешь поддержку для iOS Safari получше? Сожми трек до 128 kbps и до 2–3 минут (он зациклен через `loop`), чтобы быстрее грузился по мобильному интернету.

## 3. RSVP → Excel

Форма автоматически дублирует ответы в **localStorage** браузера гостя. Чтобы все ответы централизованно складывались в одну таблицу — настрой Google Apps Script (5 минут):

### Шаги

1. Создай новый **Google Sheet** (например, «Dilnaz RSVPs»).
2. В таблице: `Extensions → Apps Script`.
3. Удали дефолтный код, вставь содержимое файла [`apps-script.gs`](./apps-script.gs).
4. (Опционально) укажи свой email в `NOTIFY_EMAIL` — будут приходить уведомления на каждый RSVP.
5. Сохрани (`Ctrl/Cmd + S`).
6. Жми **Deploy → New deployment**.
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Жми **Deploy**, при первом разе разреши доступ.
7. Скопируй полученный **Web app URL** (выглядит как `https://script.google.com/macros/s/AK.../exec`).
8. Открой [`assets/script.js`](./assets/script.js) и вставь URL в константу:
   ```js
   const WEBHOOK_URL = "https://script.google.com/macros/s/.../exec";
   ```
9. Готово. Отправь тестовый RSVP — должна появиться строка в таблице.

### Скачать как `.xlsx`

В Google Sheets: `File → Download → Microsoft Excel (.xlsx)`. Всё.

### Альтернатива без Google

Если не хочешь возиться с Apps Script — оставь `WEBHOOK_URL = ""`. Все ответы останутся в `localStorage` браузеров **отправителей**. Это не очень удобно (данные распределены по устройствам гостей и доступны только им же), но как fallback страница всё равно работает.

Чтобы скачать ответы, которые сохранились **на конкретном устройстве** (например, на твоём ноуте, если ты тестируешь сама) — открой `admin.html` и нажми «Жүктеу .xlsx».

## 4. Деплой в интернет

Вариантов масса, выбери любой бесплатный:

| Сервис | Как |
|---|---|
| **Netlify Drop** | Зайди на [app.netlify.com/drop](https://app.netlify.com/drop), перетащи папку проекта. Получишь URL вида `xxx.netlify.app`. |
| **Vercel** | `npm i -g vercel` → `vercel` в папке проекта. |
| **GitHub Pages** | Залей в репозиторий, в Settings → Pages включи branch deploy. |
| **Cloudflare Pages** | Connect repo → Build command пустой, output dir = `/`. |

**Кастомный домен (опционально):** купи домен (например, `dilnaz-toy.kz`) и подключи в настройках хостинга — обычно это просто добавление CNAME записи.

## 5. Что подправить под реальные данные

Все правки — в [`index.html`](./index.html), искать по тегам:

- **Имя**, **дата**, **время** → в нескольких местах: cover, greeting, date section, footer.
- **Мекенжайы** (адрес) → секция `<section class="page page--venue">`. Замени текст и подставь Google Maps URL.
- **Бағдарлама** (программа вечера) → секция `page--program`. Можно удалить если не нужно.
- **Текст приветствия** → секция `.lead` в greeting.
- **Дедлайн RSVP** (по умолчанию «1 тамызға дейін») → `.rsvp-sub`.

В календаре подсвечена «6» — если когда-то поменяешь дату, не забудь обновить класс `today` на нужную ячейку в `.calendar-grid`.

## 6. Дизайн-правила

Эта страница сделана по правилам [`anti-ai-design-review`](~/.claude/skills/anti-ai-design-review/SKILL.md):

- **1 brand color** (золото `#B8975A`) + оттенки серого.
- **2 значения border-radius**: `6px` для инпутов/кнопок, `14px` для крупных блоков.
- **4 размера шрифта**: display (имя), h2 (заголовки), body, caption.
- Все цвета через CSS-переменные в `:root` — меняй там, не в компонентах.
- Анимации — `ease-out` 180–620 ms, без bounce/spring.
- Никаких иконок в цветных боксах, никаких карточек в карточках, никаких декоративных градиентов.

Если будешь править стили — держи эти правила в голове, чтобы не размыть.
